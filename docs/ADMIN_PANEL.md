# Админ-панель

Доступна только Telegram ID из `ADMIN_TELEGRAM_IDS` (по умолчанию
`5356551288`, @krinexus). Для остальных кнопка не отображается, а все
`/api/admin/*` возвращают `403 NOT_ADMIN`.

## Где открыть

В Mini App → вкладка **Профиль** → блок **🛡️ Админ-панель**.

## Что внутри

- **Обзор:** пользователи, пары, активные PRO/триалы, входы за сегодня (МСК),
  количество успешных платежей, доход в Stars.
- **Пользователи:** поиск по имени, `@username` или Telegram ID; видно пару,
  статус, срок, последний вход. Выберите пользователя → выдайте PRO.
- **Платежи:** кто, какой тариф, сколько Stars, статус, дата.
- **Выдачи:** история ручных действий администратора.

## Сроки

- 1 месяц — 30 дней
- 1 год — 365 дней
- Навсегда — 36 500 дней (в панели отображается «бессрочно»)
- Свой срок — 1…36 500 дней
- Триал — 2 дня

Срок добавляется к текущему активному сроку (если он ещё не истёк).
Кнопка «Снять» сразу переводит пару на FREE. Все действия пишутся в
`admin_grants`.

## Защита

- Проверка ID администратора на каждом `/api/admin/*`.
- RLS: `admin_grants` и `payments` недоступны клиенту; только service role.
- Админ-панель не видна другим пользователям.
- `ADMIN_TELEGRAM_IDS` — список ID через запятую, по умолчанию только
  @krinexus. В `render.yaml` уже прописан `5356551288`.

## Отслеживание входов

`users.last_seen_at` обновляется при авторизации в Mini App (не чаще раза в
5 минут). Это поле доступно только админ-панели; остальным клиентам не отдаётся.
